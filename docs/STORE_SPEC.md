# メタデータストア仕様

メタデータストアはFAT12ファイルシステムをベースに、機能を限定したサブセットを使用しデータを格納する。

## データ構造

### 先頭予約領域

基本的にはFAT12ファイルシステムの通りだが、先頭予約領域はルートディレクトリエントリ数・総セクタ数・ボリュームIDを除いて全て固定値とする。

```
ADDR | DATA
=====|================================================
0000 | EB 3C 90 4D 45 43 48 41 4C 41 42 00 02 01 01 00
0010 | 01 xx xx yy yy F8 01 00 10 00 02 00 00 00 00 00
0020 | 00 00 00 00 80 00 29 zz zz zz zz 44 41 54 41 5F
0030 | 53 54 4F 52 45 20 46 41 54 31 32 20 20 20 F4 EB
0040 | FD vv 00 00 00 00 00 00 00 00 00 00 00 00 00 00
0050 | 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
 ... | ...
01e0 | 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
01f0 | 00 00 00 00 00 00 00 00 00 00 00 00 00 00 55 AA
```

アドレス`0x0011`から2バイトの`x`で表した領域がルートディレクトリエントリ数である。32個で1KiB消費する。32の倍数が推奨される。\
アドレス`0x0013`から2バイトの`y`で表した領域がボリュームの総セクタ数である。1セクタを512バイトで固定しているため、この値は容量をKiBで表し2倍にしたものである。\
アドレス`0x0027`から4バイトの`z`で表した領域がボリュームIDである。ランダム値で良いが、フォーマット時を除きimmutableであることが望ましい。\
アドレス`0x0041`の`v`で表した領域が準拠する仕様のバージョンである。この値は常に`0x01`である。

固定値により、このファイルシステムは常に以下の通りのFAT12ファイルシステムと認識される。

|          フィールド          | 値            |
| :--------------------------: | :------------ |
|       作成したシステム       | `MECHALAB`    |
|         セクタサイズ         | 512バイト     |
|        クラスタサイズ        | 1セクタ       |
|        予約領域サイズ        | 1セクタ       |
|            FAT数             | 1個           |
|        メディアタイプ        | `0xF8`        |
|          FATサイズ           | 1セクタ       |
|   トラックあたりのセクタ数   | 16セクタ      |
|           ヘッド数           | 2個           |
| ボリューム手前の隠れセクタ数 | 0セクタ       |
|         ドライブ番号         | `0x80`        |
|       ボリュームラベル       | `DATA_STORE␠` |
|    ファイルシステムタイプ    | `FAT12␠␠␠`    |

### FAT領域

基本的にはFAT12ファイルシステムの通りだが、先頭予約領域の通りFAT領域は1つとし、最終クラスタ(セクタ)を表すFATエントリは常に`0xFF7`としてデータが利用しないようにする必要がある。

### データ領域

最終クラスタ(セクタ)は、先頭にボリュームの総セクタ数(`BPB_TotSec16`)をリトルエンディアンで格納する。
